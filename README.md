- **القبلة**: تنبيه أن البوصلة تعمل على الهاتف فقط.
- **عدّاد الأذكار (الوضع النهاري)**: الخط الدائري الذهبي أصبح واضحًا وسميكًا.
- **من نحن**: «ويجعل القرآن بين يديك والتفسير».
