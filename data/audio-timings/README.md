# توقيتات مزامنة الآيات

الوحدة `quran-audio-sync.js` هي نسخة التوقيتات المحسّنة المأخوذة من ملف المستخدم `rafiq-almuslim-v14-audio-sync-real-timestamps.zip`. عند تشغيل قارئ وسورة يدعمهما جدول `MP3QURAN_READ_ID`، تجلب توقيتات بداية ونهاية الآيات من:

`https://www.mp3quran.net/api/v3/ayat_timing?read={readId}&surah={surah}`

وتقبل أيضًا توقيتات محلية اختيارية في `data/audio-timings/{reader}/{surah}.json` أو بيانات مضمنة في `window.RFQ_AUDIO_TIMINGS`. يُحوّل المحمّل قيم التوقيت بالمللي ثانية إلى ثوانٍ ويستخدمها لتظليل الآية وتحريك صفحة المصحف. إذا لم تتوفر توقيتات قابلة للاستخدام، يستخدم تقديرًا من أوزان الآيات ويضع علامة `estimated` بدل الادعاء بأن الموضع دقيق؛ أما التوقيتات الفعلية فعلامتها `exact`.

تقليب صفحات المصحف الناتج عن المزامنة يمر عبر علامة `window.__rfqAudioPageSync`، حتى لا يغيّر سجل «آخر صفحة قرأتها يدويًا» الذي يستخدمه زر استكمال القراءة.
